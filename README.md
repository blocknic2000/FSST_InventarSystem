# 🎒 InventarSYS

Ein modernes Inventar-, Ausleih- und Reservierungssystem, entwickelt als Schulprojekt der **HTL Anichstraße Innsbruck** im Rahmen des **Competence Center Anichstraße (CCA)**.

InventarSYS ermöglicht die zentrale Verwaltung von Inventargegenständen, Benutzern, Reservierungen und Ausleihen über eine moderne Weboberfläche sowie eine Python-API für externe Anwendungen.

---

## 📖 Projektbeschreibung

InventarSYS wurde entwickelt, um die Verwaltung von Schulinventar zu vereinfachen.

Das System bietet:

* Verwaltung von Inventargegenständen
* Ausleihsystem
* Reservierungssystem
* Benutzerverwaltung
* Administrationsbereich
* Protokollierung aller Aktionen
* Dokumentationssystem
* Python-API für Desktop-Anwendungen

---

## ✨ Funktionen

### 👤 Benutzerverwaltung

* Benutzer erstellen
* Benutzer bearbeiten
* Benutzer löschen
* Rollenverwaltung
* Passwortänderung
* Login-System

### 🎒 Artikelverwaltung

* Artikel erstellen
* Artikel bearbeiten
* Artikel löschen
* Artikelbilder
* Statussystem

### 📤 Ausleihsystem

* Artikel ausleihen
* Rückgabe erfassen
* Übersicht aller Ausleihen
* Historie

### 📅 Reservierungssystem

* Reservierungen erstellen
* Reservierungen abschließen
* Reservierungsübersicht

### 📝 Logging

* Benutzeraktionen protokollieren
* Adminaktionen protokollieren
* Nachvollziehbare Änderungen

### 📚 Dokumentation

* Eigene Dokumentationsplattform
* Dynamische Seiten
* Suchfunktion

---
